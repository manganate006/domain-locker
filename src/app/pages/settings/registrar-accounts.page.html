Automatic Sync (Cron)

Enable automatic synchronization to fetch new domains from your registrars on a schedule. Add the cron command below to your server to run the sync automatically.

{{ getMaskedApiKey() }}
0 5 * * * curl -s -X POST "{{ autofetchApiKey ? 'YOUR_URL' : '...' }}/api/registrar-autofetch?key=..."

This cron runs daily at 05:00. Only accounts with "Auto-sync" enabled will be synchronized.
